A data analyst finds answers in data and explains them clearly. Learn the tools in this order and practise each one on real datasets.

## Stage 1: Excel and basic statistics
- Formulas, filters, pivot tables and charts
- Average, median, percentages and simple probability
- Cleaning messy data: duplicates, missing values, wrong formats

**Build:** a small sales or marks report with a pivot table and a chart.

## Stage 2: SQL
- SELECT, WHERE, ORDER BY, GROUP BY
- JOINs across tables
- Subqueries and aggregate functions

**Build:** answer 10 questions about a sample database, such as the top products or the average marks per class.

## Stage 3: Python for data
- Python basics from our [Python course](/python/)
- Reading CSV files and cleaning data
- Libraries such as pandas for tables and matplotlib for charts

**Build:** clean a public dataset and show three findings with charts.

## Stage 4: Visualisation and communication
- A dashboard tool such as Power BI or Tableau
- Writing a short summary of what the data shows and what to do about it

**Build:** a one-page dashboard with a short written explanation.

## Stage 5: Portfolio and applications
- 2 to 3 projects on GitHub or a simple page, each with the question, the data, the method and the result
- A resume that lists tools and results. Use the [Free Resume Builder](/tools/free-resume-builder.html)
- Interview practice: SQL questions, case questions and [HR questions](/career/hr-interview-questions)
