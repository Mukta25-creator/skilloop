Fix these before you apply anywhere.

## Layout and format

1. **Too long.** Keep it to one page as a student.
2. **Fancy designs.** Tables, columns and graphics can confuse ATS software.
3. **Tiny fonts.** Use at least 10 to 11 point.
4. **Inconsistent formatting.** Use the same fonts, spacing and date style everywhere.
5. **Wrong file name.** Use `Name_Resume.pdf`, not `resume_final_final2.pdf`.
6. **Image-only PDF.** If you cannot select the text, the system cannot read it.

## Content

7. **No keywords from the job.** Read the job post and use its important words where they are true for you.
8. **Vague skills.** "Good at computers" says nothing. List specific tools and languages.
9. **Listing duties, not results.** "Made a website" is weaker than "Built a website used by 200 students."
10. **Projects without details.** Say what you built, which tools you used and what it did.
11. **No numbers.** Add numbers where you honestly can: users, marks, speed, team size.
12. **Long objective paragraph.** Use a 2-line summary or skip it.
13. **Irrelevant details.** Hobbies, full address and family details are usually not needed.
14. **Weak action words.** Start bullets with verbs such as built, designed, analysed, led, improved.

## Honesty and basics

15. **Skills you cannot explain.** If it's on your resume, an interviewer may ask about it.
16. **Spelling and grammar errors.** Read it aloud and ask a friend to check.
17. **Unprofessional email.** Use a simple email like `firstname.lastname@gmail.com`.
18. **Missing links.** Add your GitHub or LinkedIn link if the profile is ready to be seen.
19. **One resume for every job.** Adjust your skills and project order for each role.
20. **Not checking before sending.** Run your resume through a keyword check before you apply.
