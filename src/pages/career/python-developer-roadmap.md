This roadmap shows the order to learn things in. The time for each stage depends on how much you practise, so move on when you can build something at that level, not when a number of weeks has passed.

## Stage 1: Python basics
- Variables, data types, operators, if-else, loops, functions
- Lists, tuples, sets and dictionaries
- Reading and writing files, handling errors

**Build:** a number guessing game and a to-do list app. Both are in our [Python course](/python/).

## Stage 2: Core programming skills
- Object-oriented programming: classes, inheritance
- Modules, packages and `pip`
- Git and GitHub to save and share your code
- Basic data structures and algorithms: sorting, searching, stacks, queues

**Build:** a student marks tracker that saves data in a file.

## Stage 3: Databases and the web
- SQL: SELECT, WHERE, JOIN, GROUP BY
- A web framework such as Flask or Django
- Building and using simple REST APIs
- Basic HTML and CSS

**Build:** a small web app with a login, a database and a few pages.

## Stage 4: Job-ready skills
- Writing tests for your code
- Reading other people's code and fixing bugs
- A resume with 2 to 3 solid projects and your GitHub link
- Interview practice: [Python interview questions](/python/interview-questions) and [HR questions](/career/hr-interview-questions)

## Check your progress
- Can you explain every project on your resume in your own words?
- Is your code on GitHub with a clear README?
- Can you solve easy problems without looking up the answer?

Then build your resume with the [Free Resume Builder](/tools/free-resume-builder.html).
