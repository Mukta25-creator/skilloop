ATS stands for **Applicant Tracking System**. Companies use it to collect, store and search the resumes they receive.

## What an ATS does with your resume

1. **Reads (parses) your file** and tries to split it into fields such as name, education, skills and projects
2. **Stores** the information in a database
3. **Lets recruiters search and filter**, for example by skill, degree or college
4. **May rank candidates** based on how well the resume matches the job

Not every company uses it in the same way. Some recruiters read every resume, others search by keywords first. So a resume that is easy to read for software and clear for humans is the safest choice.

## What can go wrong

| Problem | What may happen |
|---|---|
| Tables, columns and text boxes | Text is read in the wrong order or skipped |
| Information in headers and footers | Contact details are missed |
| Icons, images and graphics | Content inside them is not read |
| Creative headings like "My Journey" | The system cannot find your education or skills |
| Scanned or image-only PDFs | No text can be read at all |

## How to make your resume ATS-friendly

- Use a **simple one-column layout**
- Use **standard headings**: Education, Skills, Projects, Experience, Certifications
- Use a common font such as Arial or Calibri
- Add skills and keywords **that appear in the job description**, only where they are true for you
- Save as a **PDF with real text**, unless the job post asks for another format
- Use a clear file name like `Mukta_Resume.pdf`

## A quick test you can do

1. Open your resume and select all the text.
2. Copy it into a plain text editor like Notepad.
3. Read what appears. If the order is mixed up or parts are missing, an ATS may see it the same way.
