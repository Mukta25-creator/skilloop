If you have no work experience, your resume should show your skills, projects and education clearly.

## Section order for freshers

1. Name and contact details
2. Short summary (2 lines, optional)
3. Education
4. Skills
5. Projects
6. Internships or experience (if any)
7. Certifications and achievements

## Simple template

```
YOUR NAME
City | Phone | Email | LinkedIn | GitHub

SUMMARY
Final-year B.Tech student with skills in Python and SQL, looking for a software internship.

EDUCATION
B.Tech, Computer Science - College Name, University (2023 - 2027)  CGPA: 8.2
12th - School Name (2023)  85%

SKILLS
Languages: Python, SQL, JavaScript
Tools: Git, VS Code, Excel
Concepts: Data structures, OOP, REST APIs

PROJECTS
Student Marks Tracker | Python, SQL
- Built a command-line app to store and analyse marks of 50+ students
- Wrote SQL queries to find averages and top scorers
- Published the code on GitHub

CERTIFICATIONS
Python for Everybody - Platform Name (2025)
```

## How to write strong bullet points

Use this pattern: **action word + what you did + result or detail**.

| Weak | Stronger |
|---|---|
| Worked on a website | Built a 5-page website using HTML and CSS for a college event |
| Did a Python project | Wrote a Python script that cleaned a 2,000-row dataset |
| Member of a club | Organised a coding workshop attended by 60 students |

Only include numbers and results that are true.

## Quick checklist

- One page, one column
- Standard headings
- Real, specific skills
- Two or three solid projects
- No spelling mistakes
- Saved as a text-based PDF
