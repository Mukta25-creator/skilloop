Python is a simple, powerful programming language used for web development, data science, automation, AI and more. Its code reads almost like English, which makes it a great first language.

## Why learn Python?

- Easy to read and write
- Used by companies of all sizes
- Huge number of free libraries
- Popular for placements, internships and data jobs

## How to run Python

1. Install Python from python.org, or use any free online Python editor in your browser.
2. Create a file named `hello.py`.
3. Run it with `python hello.py` in the terminal.

## Your first program

```python
print("Hello, World!")
```

Output:

```
Hello, World!
```

## Comments

Lines starting with `#` are ignored by Python. Use them to explain your code.

```python
# This prints a greeting
print("Hello, Python!")
```
